# פנייה מוכנה למוקד העירוב (054-8483320, טופס צור קשר ב-hiruv.com)

שלום רב,

תודה רבה על האישור להשתמש במפות ובנתונים של מוקד העירוב בתוסף "גבולות עירוב" לתוכנת אוצריא.
התוסף מציג את המפות השכונתיות ואת רשימת האחראים, ובכל מסך מופיעה הפניה למוקד ולאחראי המקומי לפני שבת.

כדי שהמידע יהיה מלא ומדויק, נשמח לקבל:
1. את קובצי המקור של המפות ברזולוציה מלאה, ואם יש גם בפורמט וקטורי (PDF, KML, SHP או כל פורמט של קווים), כדי שהמפות יישארו חדות בהגדלה.
2. מפות לשכונות שמופיעות ברשימת האחראים בלי מפה, למשל בבני ברק: פרדס כץ, קרית הרצוג, שיכון ה', גן ורשא. וכן בבאר שבע, בת ים, חצור, מיצד וקרית מלאכי.
3. את הדרך המועדפת עליכם לעדכן אותנו כשעירוב משתנה או נפסל, כדי שנוכל להוסיף לתוסף את תאריך העדכון האחרון.
