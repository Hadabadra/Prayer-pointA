# כיוון תפילה 3.3 — מצב (25.10.2026)

## מה נעשה
- **3.3.0** — סרגל עליון בשורה אחת: `overflow.js` מעביר כפתורים שלא נכנסים לתפריט ⋯ (`#ovfMenu`), לפי סדר עדיפות `ORDER`. ההסתרה הישנה של `.sec` בטלפון (ui.css) בוטלה לטובתו.
- **3.3.0** — אריזה לדפדפן: `kivun-tefila-build/web.py kivun-tefila OUT` יוצר
  - `kivun-tefila-<v>.html` — קובץ אחד. כל ה-CSS/JS מוטמעים; קבצים שנטענים בעת הצורך (st-*.js, postcodes.js…) מוטמעים כ-`<script type="text/x-kf" data-n=…>` ב-head, ו-shim על `HTMLScriptElement.src` מחליף אותם ב-Blob URL.
  - `kivun-tefila-<v>-browser.zip` — תוסף Manifest V3 לכרום/אדג'. סקריפטים בתוך הדף מוצאים ל-inline-N.js (MV3 אוסר inline). `bg.js` פותח את index.html בלשונית.
  - ה-workflow `kivun-release.yml` מריץ את web.py ומצרף את שניהם לכל Release.
  - כרום לא מתקין ‎.crx מחוץ לחנות. להתקנה בלחיצה אחת צריך חנות אדג' (חינם) או כרום (5$) — רישום על ידי המחברת.
- **3.3.1/3.3.2** — `panels.js`: כותרת קבועה (`.pnlHd`) עם ✕ לחלוניות הצד (הגדרות, הורדות, הלכות, זיהוי ידני, אודות, מניינים, טיסה, הכותל, ביקורים); נוספת מחדש אם החלונית נבנית מחדש. עיצוב ככרטיסים ב-modern.css (סוף הקובץ).
- **3.3.1** — חיפוש רחוב ב-Enter בלבד; `#stGo`/`#fGo` מוסתרים ב-CSS.
- **3.3.2** — `web-mode.js` (רק בלי אוצריא): מסתיר הורדת סידורון; "תפילה" מאפשר הדבקת נוסח / טעינת txt, נשמר ב-localStorage (`kivun-web-prayer`).

- **3.3.3** — 3.3.2 נדחתה בחנות: בתגית "מראה תואם" אסור border-radius ב-px (גם 999px); רק var(--radius-sm/md/lg/pill).

- **3.4.0** — `restyle.js`: בונה מחדש את #set ו-#dlp לסעיפים (`.ks-sec` / `.ks-h` / `.ks-card`), שורות (`.ks-row`: טקסט + `.ks-ctl`), כרטיסי הורדה (`.ks-dl`: `.ks-ico` + `.ks-body`, כפתור ראשי `.ks-pri`, משניים `.ks-sec-b`) והסברים (`details.ks-more`). רק מזיז אלמנטים קיימים — המאזינים נשמרים; רץ שוב כשהחלונית נפתחת (MutationObserver), פעם אחת לחלונית (`data-ks`). CSS בסוף modern.css.

- **3.5.0** — הלכות במראה מודרני (modern.css, סוף הקובץ, `#hal details.hsec`, `blockquote`, `.hsrc`, `button.src`, `button.fl`); כפתור `#bFind` עם כיתוב `.bl` (מוחרג מכלל הסתרת הכיתובים ב-96rem); במסך מלא `#stRotRow` fixed בשורה אחת (הכלל של ui.css גבר קודם).

## פתוח
- ב-Release של 3.3.1 החבילה כוללת בטעות 3 צילומי מסך (‎+0.7MB, בלי השפעה). תוקן מ-3.3.2.
- נוסח תפילה מובנה בדפדפן (במקום הדבקה) — לא נעשה; דורש מקור נוסח מאושר.
- פרסום לחנות תוספי אדג'/כרום — ממתין לרישום מפתחת.
- לא נבדק בתוך אוצריא עצמה (נבדק ב-Chromium).
- צילומי בדיקה: לשמור מחוץ ל-kivun-tefila/ (pack.py אורז כל קובץ בתיקייה).

- **3.5.1** — issue #1: ב-`map()` (index.html) הנקודה בקצה הקו לירושלים הוחלפה בראש חץ (`H(from,to)` — משולש בכיוון הקטע האחרון), גם ב-near (חץ מהמיקום) וגם ב-far (הקטע האחרון של הקו המקווקו). issue #2: `rhDist(a,b)` — מרחק לאורך הקו הקבוע (רוחב איזומטרי, q=Δφ/Δψ, ובקו רוחב קבוע q=cosφ); `locText()` מציג `dist` בשיטת כדור ("בקו הקצר") ו-`rhDist` בשיטת מפה ("לאורך הכיוון הקבוע"). שינוי שיטה קורא ל-`draw()` → `locText()`, כך שהמרחק מתעדכן. issue #3 נסגר — שורת הכלים כבר מתחת למפה (v31.js, `#mapTool`/`#stRotRow`).
- אריזה: CI משווה בייט-לבייט ל-pack.py על ubuntu (zlib רגיל). Python עם zlib-ng (בסביבות Claude) נותן קובץ שונה → ה-Release נכשל. לארוז ב-Python עם zlib רגיל (למשל `uv python install 3.12`).

- **3.5.2** — דיווחי משתמשים:
  - #8 `selfix.js`: הבחירה ברשימה של הדף עברה מ-mousedown ל-click (הרשימה נסגרה באמצע הלחיצה וה-click נפל למפה שמתחת); click/pointerup/mouseup ב-400ms שאחרי סגירה נבלעים. `dlcountry.js`: רשימת מדינות עם קובץ מוכן (`HAS`: כבישים — ISR AUS AUT BEL CHE GBR HUN NLD UKR ZAF; שכבות — ISR). למדינה אחרת, הורדה/קישור מציגים הודעה (הקישור הוביל ל-404). כשמוסיפים קבצים ל-Release `kivun-tefila-data` — לעדכן את `HAS`. שלוחת אייקול לא מופיעה בתוסף — אין מה לעדכן.
  - #6 `st-08.js` (רמת בית שמש): שני קטעי secondary שתויגו "תלמוד בבלי" ב-OSM הם המשך אליהו הנביא — שונו ידנית. בבנייה מחדש של הקובץ (build_streets.py) התיקון יידרס; לתקן ב-OSM. בית הכנסת "תפארת מרדכי – קאשוי" — לא נוסף.
  - #5 `streets.js`, `globe.js`: `var ARW(f,t)` — ראש חץ במקום נקודה בקצה הקו לירושלים (בכדור — לפי הקו הנבחר).
  - #4 `ui.js`: הגדרת מסך הפתיחה נשמרת גם באוצריא וגם ב-localStorage, ונקראת משניהם (`v` יכול להיות אובייקט `{value}`); במסך עצמו `#spNoC` "אל תציג שוב".
- **3.5.3** — #6 הושלם: תיקונים ידניים לנתוני רחובות נמצאים ב-`kivun-tefila-build/overrides.json` (לפי מפתח אזור: `rename` לפי שם+סוג דרך, `syn` בתי כנסת חסרים) ומוחלים ב-`split_streets.py` בכל בנייה — כך שבנייה מחדש לא דורסת אותם. נוסף "תפארת מרדכי – קאשוי" (מיקום מקורב, פינה דרום-מזרחית של נהרדעא/תלמוד ירושלמי). תיקון קבוע במקור — רק ב-OSM.

- **3.5.4** (01.11.2026) — מפה משותפת (#11): `kivun-tefila/maplink.js` מוסיף מתחת למפה שורה "שכבות" עם הכפתורים ↗ מקוואות ו↗ גבולות עירוב. הם פותחים את התוסף ההוא באותו מיקום (`plugin.openOther` עם `param {type:"open-map",lat,lon}`), ואם הוא לא מותקן מוצג קישור לחנות. ובכיוון ההפוך: `open-map` שמתקבל מציב את המיקום (setPos). המקור הראשי של קוד המפה המשותף הוא `shared/` במאגר Hadabadra/Mikvaot (תוכנית: `shared/map-core/SHARED-MAP.md`). המעבר המלא של המפה של כיוון תפילה ל-map-core נשאר פתוח (שלב 4 שם). רשימת התוספים ב-maplink.js מתעדכנת יחד עם `MapUI.PLUGINS`.
