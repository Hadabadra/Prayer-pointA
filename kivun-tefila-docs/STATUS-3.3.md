# כיוון תפילה 3.3 — מצב (25.10.2026)

## מה נעשה
- **3.3.0** — סרגל עליון בשורה אחת: `overflow.js` מעביר כפתורים שלא נכנסים לתפריט ⋯ (`#ovfMenu`), לפי סדר עדיפות `ORDER`. ההסתרה הישנה של `.sec` בטלפון (ui.css) בוטלה לטובתו.
- **3.3.0** — אריזה לדפדפן: `kivun-tefila-build/web.py kivun-tefila OUT` יוצר
  - `kivun-tefila-<v>.html` — קובץ אחד. כל ה-CSS/JS מוטמעים; קבצים שנטענים בעת הצורך (st-*.js, postcodes.js…) מוטמעים כ-`<script type="text/x-kf" data-n=…>` ב-head, ו-shim על `HTMLScriptElement.src` מחליף אותם ב-Blob URL.
  - `kivun-tefila-<v>-browser.zip` — תוסף Manifest V3 לכרום/אדג'. סקריפטים בתוך הדף מוצאים ל-inline-N.js (MV3 אוסר inline). `bg.js` פותח את index.html בלשונית.
  - ה-workflow `kivun-release.yml` מריץ את web.py ומצרף את שניהם לכל Release.
  - כרום לא מתקין ‎.crx מחוץ לחנות. להתקנה בלחיצה אחת צריך חנות אדג' (חינם) או כרום (5$) — רישום על ידי המחברת.
- **3.3.1/3.3.2** — `panels.js`: כותרת קבועה (`.pnlHd`) עם ✕ לחלוניות הצד (הגדרות, הורדות, הלכות, זיהוי ידני, אודות, מניינים, טיסה, הכותל, ביקורים); נוספת מחדש אם החלונית נבנית מחדש. עיצוב ככרטיסים ב-modern.css (סוף הקובץ).
- **3.3.1** — חיפוש רחוב ב-Enter בלבד; `#stGo`/`#fGo` מוסתרים ב-CSS.
- **3.3.2** — `web-mode.js` (רק בלי אוצריא): מסתיר הורדת סידורון; "תפילה" מאפשר הדבקת נוסח / טעינת txt, נשמר ב-localStorage (`kivun-web-prayer`).

- **3.3.3** — 3.3.2 נדחתה בחנות: בתגית "מראה תואם" אסור border-radius ב-px (גם 999px); רק var(--radius-sm/md/lg/pill).

- **3.4.0** — `restyle.js`: בונה מחדש את #set ו-#dlp לסעיפים (`.ks-sec` / `.ks-h` / `.ks-card`), שורות (`.ks-row`: טקסט + `.ks-ctl`), כרטיסי הורדה (`.ks-dl`: `.ks-ico` + `.ks-body`, כפתור ראשי `.ks-pri`, משניים `.ks-sec-b`) והסברים (`details.ks-more`). רק מזיז אלמנטים קיימים — המאזינים נשמרים; רץ שוב כשהחלונית נפתחת (MutationObserver), פעם אחת לחלונית (`data-ks`). CSS בסוף modern.css.

## פתוח
- ב-Release של 3.3.1 החבילה כוללת בטעות 3 צילומי מסך (‎+0.7MB, בלי השפעה). תוקן מ-3.3.2.
- נוסח תפילה מובנה בדפדפן (במקום הדבקה) — לא נעשה; דורש מקור נוסח מאושר.
- פרסום לחנות תוספי אדג'/כרום — ממתין לרישום מפתחת.
- לא נבדק בתוך אוצריא עצמה (נבדק ב-Chromium).
- צילומי בדיקה: לשמור מחוץ ל-kivun-tefila/ (pack.py אורז כל קובץ בתיקייה).
