# כיוון תפילה 2.8 — הלכות הכותל וקריעה (בעבודה)

בקשת המפתחת (20.10.2026):
1. כפתור **"קריעה בכותל"**: הלכות קצרות מאוד + נוסח הפסוקים שאומרים בשעת הקריעה (מתוך הגמרא, מו"ק כו ע"א, כפי שמובא בקובץ).
2. **הלכות הכותל המלאות** מהקובץ `kivun-tefila-docs/זכר לחורבן - דור המלקטים.docx` (סימנים תק"ס–תקס"א):
   סיכום הנושאים והשיטות, עם **שם הפוסק ומראה המקום בלבד — בלי הציטוטים** (בקשה מפורשת).
3. **חיפוש** בתוך ההלכות.
4. **כל מראה מקום נפתח בספריית אוצריא** (`openSrc` ב-extras.js: library.findBooks → reader.openBookAtRef, ואם לא נמצא — reader.openSearchTab).
5. **מה שקיים כעת (KOTEL_DINIM ב-kotel-dinim.js) נשאר** — רק מראי המקומות שבו נעשים לחיצים ונפתחים באוצריא.
6. הקובץ המקורי שמור בגיט (kivun-tefila-docs).

## טכני
- המרה: `python3 kivun-tefila-build/kotel_docx.py "kivun-tefila-docs/זכר לחורבן - דור המלקטים.docx" kivun-tefila/kotel-full.js`
  (python-docx). הפלט `window.KOTEL_FULL`; הציטוטים מוסרים בסקריפט (strip_quotes). לא לערוך את kotel-full.js ידנית.
- קיצורים → שם ספר בספרייה: טבלת KOTEL_BOOKS ב-kotel-full-ui.js (מחבר/רמ"א → שולחן ערוך אורח חיים לפי הסימן, מ"ב → משנה ברורה, וכו').
