## כיוון תפילה — קובצי נתונים

**הכי פשוט:** הורידו את `kivun-tefila-all-data.json` (כל הנתונים בקובץ אחד), ובתוסף: הגדרות ← הורדות ← "טען את כל הנתונים מקובץ".

כל הקבצים כאן מתחילים ב-`kivun-tefila-` — כך ברור שהם שייכים לתוסף "כיוון תפילה":

| קובץ | מה בו |
|---|---|
| `kivun-tefila-all-data.json` | **כל הנתונים יחד** (כל השורות שבטבלה) |
| `kivun-tefila-geo-names.json` | שמות ערים ומקומות בעברית לחיפוש |
| `kivun-tefila-geo-extra.json` | נהרות ואגמים מפורטים למפה |
| `kivun-tefila-roads-XXX.json` | כבישים ראשיים במדינה XXX (קוד בן 3 אותיות, למשל GBR = בריטניה) |
| `kivun-tefila-layers-XXX.json` | בתי כנסת, תחנות רכבת ושדות תעופה במדינה XXX |

קבצים ישנים בלי הקידומת (`roads-…`, `layers-…`, `geo-…`) שייכים גם הם לכיוון תפילה ועדיין נטענים.
